# Smart Electricity Usage Monitor

A simple web app to track monthly electricity consumption from meter readings and monitor the 200-unit limit.

## Features
- Add cumulative meter readings with dates
- Monthly usage, units remaining, and a progress bar
- Reading history table
- Data saved in the browser (localStorage)

## Tech
HTML, CSS, JavaScript (no frameworks, no build step)

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Push all files to a GitHub repository
2. Go to **Settings → Pages**
3. Under **Source**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`

## Note
This is a consumption tracker, not an official eligibility checker for any government scheme.
